最初の版です（Android）。

- チラシをスキャン（Googleのドキュメントスキャナー：端の検出・傾き補正・複数ページ・ギャラリーから）
- QRコードをスマホで読み取り（Zoom などのWeb参加URL）
- Gemini で読み取り：会の名前、日時、会場・住所・電話・アクセス、Web参加（URL・ID・パスコード）、主催・製品、プログラム（演題・座長・演者）、申込、注意書き、要約。地図の面・名刺も同時に読み取り
- Googleカレンダーに登録：概要とプログラムを説明欄に、チラシ画像をGoogleドライブに保存して予定に添付。内容の更新・取り消し
- 設定なしで使える「カレンダーアプリで登録」（画像の添付なし）
- 一覧（これから／未登録／Web参加／過去、検索）とカレンダー表示
- 名刺を連絡先に追加、地図・経路、共有、Markdownで保存、バックアップ

実機での確認はまだです（画面はブラウザでの自動テストで確認済み）。
