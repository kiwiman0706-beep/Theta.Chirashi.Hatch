**Theta Hatch シリーズの新しいアプリ ID（`app.thetahatch.chirashi`）とシリーズ共通の署名鍵**になった最初の版です。0.1 とは別のアプリとして入ります。

- 0.1 からの移行：Theta Home Hatch の「新しいアプリに移る」案内で、0.1.1 の書き出し → この版での読み込み（`app.thetahatch.action.IMPORT`）→ 0.1 の削除まで進みます。Home が無いときは、0.1.1 の 設定 →「チラシと画像を書き出す」で保存した zip を、この版の「書き出しファイルから読み込む」で選びます
- スキン：シリーズ共通の 6 つ（端末に合わせる・ダーク・ライト・POP・ALERT・SCI-FI）
- Home Hatch（KidsHome Hatch）から共通設定を受け取る：スキン・Gemini のモデル・Google アカウント、Gemini APIキー（「Home Hatch のキーを使う」）。項目ごとに「シリーズに合わせる」を切り替えられます
- 更新：設定の「更新を確認」→「更新する」で Home Hatch の更新画面を開きます（Home が無ければ Releases のページ）
- Google ログイン：シリーズの Google Cloud プロジェクトに登録済み

チラシの画像を Google ドライブにあげ直すため、0.1 で登録した予定を「内容を更新」すると画像が新しいフォルダにもう一度保存されます。実機での確認はまだです。
